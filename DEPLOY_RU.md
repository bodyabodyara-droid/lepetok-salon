# Сайт салона «Лепесток» — публикация

## Что уже подготовлено
- index.html — адаптивная страница салона и форма записи.
- server.py — обработчик заявок, валидация, сохранение в SQLite локально или PostgreSQL при заданном DATABASE_URL, уведомление в Telegram.
- render.yaml — описание веб-сервиса Render.
- requirements.txt — зависимость PostgreSQL.

## Перед публикацией
1. Создать бесплатную PostgreSQL-базу (например, в Supabase) и взять строку подключения PostgreSQL.
2. Поместить папку site в отдельный GitHub-репозиторий. Не загружать .env, токен бота, локальные базы или любые секреты.
3. В Render создать Web Service из репозитория. Можно использовать render.yaml.
4. Задать переменные окружения:
   - BOT_TOKEN — токен Telegram-бота (секрет, не публиковать).
   - ADMIN_ID — числовой Telegram ID администратора.
   - DATABASE_URL — строка PostgreSQL из панели базы данных.
5. После запуска проверить /api/health, отправить тестовую заявку и убедиться, что она есть в базе и уведомление приходит в Telegram.

## Важные ограничения
- Не передавать токен бота в исходный код или GitHub.
- Не считать форму готовой для клиентов, пока не проверены уведомления и сохранение данных на опубликованном сервисе.
- Бесплатный веб-сервис может засыпать; первая загрузка после простоя может быть медленной.
- База данных должна быть отдельной от файловой системы веб-сервиса, потому что локальные файлы бесплатного хостинга могут сбрасываться.
- Цены на окрашивание и брови намеренно обозначены как «Стоимость уточняется».
